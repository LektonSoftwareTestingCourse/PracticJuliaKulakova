# Тестовый план СМП

## 1. Область и подход

**Область:** обязательный функционал 11 сервисов СМП и инфраструктуры (PostgreSQL, RabbitMQ). Ядро (Authorization, Card Management) тестируется глубоко
, периферия (Gateway, Switch, симуляторы, Transaction Logger, Web Dashboard) - более общими решениями

**Подход:** риск-ориентированный

## 2. Критерии входа и выхода

### 2.1. Критерии входа 

- `docker compose up -d` поднимает все 11 сервисов, PostgreSQL и RabbitMQ без ошибок
- `docker compose ps` - все контейнеры в состоянии `Up (healthy)`
- сгенерировано не менее 100 тестовых карт (`POST /api/cards/generate`)
- зафиксированы версия сборки и `.env`, тестовые данные воспроизводимы
- e2e-набор из `services/e2e-tests` запускается и проходит на локальном стенде
- модель попарного тестирования сгенерирована: `pict/model.txt` → `cases.txt`, `pict/model-cms.txt` → `cases-cms.txt`
- известные ограничения зафиксированы заранее (неатомарность резервирования, rate-limit Gateway).

### 2.2. Критерии выхода

**Критерий выхода по системе.** Тестирование СМП считается завершённым на неделе 16. Все восемь
артефактов roadmap закрыты, открытых дефектов Blocker и Critical нет, покрытие по уровням пирамиды зафиксировано в coverage map (артефакт 8). До этого
момента тестирование не завершено. Отсутствие любого артефакта roadmap означает, что часть системы
не проверена соответствующим уровнем.

## 3. Инструменты, язык, фреймворк и окружение

| Компонент | Чем работаем | Назначение |
|---|---|---|
| Язык и фреймворк | Java 21 (Temurin), Spring Boot 3.4.1, Maven (многомодульная сборка, профили `-P<service>`) | все 9 бэкенд-сервисов |
| Фронтенд | Node 24, React 18, TypeScript 5.7, Vite, Vitest + Testing Library | Web Dashboard |
| БД и брокер | PostgreSQL 16-alpine, RabbitMQ 3.13-management | карты, лимиты, очередь транзакций |
| Запуск стенда | Docker Desktop, `docker compose`, `Makefile` (`make run / status / logs / smoke`) | поднять весь стенд одной командой |
| Тест-фреймворки | JUnit 5 + Mockito (unit); TestNG 7.10.2 + REST Assured 5.4.0 + Awaitility + Hamcrest (`services/e2e-tests`) | уровни проверок: unit → api → e2e |
| Тест-дизайн | PICT 3.7.4 (2-wise, `/s` — статистика); Python 3.9+ и `allpairspy` как резерв | `pict/model*.txt` → `cases*.txt` |
| Инструменты проверки | `scripts/smoke-test.sh`, `scripts/load-smoke.sh`, `curl`, `jq`, `psql` | прогоны и разбор результатов |
| Качество и CI | Checkstyle 10.12.4 (`maven-checkstyle-plugin` 3.6.0, `services/checkstyle.xml`, `make mvn-lint`), ESLint, GitHub Actions (JDK 21 Temurin, Node 24, кеш Maven) | quality gates |
| Наблюдаемость | Prometheus, Grafana, Loki, Promtail | метрики и логи сервисов |
| Тестовые данные | `POST /api/cards/generate`, фикстуры `limit_usage`, наборы `docs/practice-2/pict/` | воспроизводимость кейсов |
